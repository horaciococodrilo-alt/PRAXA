# Archivo histórico

Esta carpeta puede contener cuadernos, Lean Canvas, investigaciones y diagramas anteriores.

Todo material aquí tiene estado **ARCHIVADO Y NO NORMATIVO**.

- Puede explicar el origen de una decisión.
- No define alcance actual.
- No autoriza features.
- No prevalece sobre `docs/architecture/company-brain-spec.md`.
- No debe cargarse automáticamente en todas las sesiones del agente.

Cuando una idea histórica vuelva a ser relevante, debe convertirse primero en hipótesis, ADR o ticket nuevo aprobado.
