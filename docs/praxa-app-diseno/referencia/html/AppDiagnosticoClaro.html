Tu negocio muestra un crecimiento en ventas,
pero con una menor eficiencia publicitaria.

Durante los últimos 30 días, las ventas aumentaron un 12%, mientras que la inversión en Meta Ads creció un 21%. Esto significa que estás generando más ventas, pero necesitás una inversión proporcionalmente mayor para conseguirlas.

La principal caída se concentra en las campañas de adquisición. En cambio, las campañas dirigidas a usuarios que ya interactuaron con tu marca mantienen un rendimiento más estable.

Resumen ejecutivo

El briefing adjunto te define un tema de investigación concreto: construir un diagnóstico del negocio en base a datos de sistemas como Meta Ads, GA4, Tiendanube y otras fuentes relevantes, para entender su rendimiento actual, identificar oportunidades y proponer recomendaciones accionables.

El análisis resultante combina la información de todos los sistemas para ver el negocio de forma integral, considerando marketing, ventas, tráfico, conversión, productos y entendiendo cómo se relacionan entre sí. Por lo tanto, no aplico el fallback de proponer temas alternativos.

El modelo de diagnóstico sugiere analizar el negocio en cuatro módulos principales:

  1. Adquisición: Meta Ads y tráfico (GA4) → visitas → costo por adquisición → calidad de tráfico;
  2. Conversión y ventas: GA4 + Tiendanube → comportamiento en la web → compras → ingresos;
  3. Productos: performance por categoría y producto → márgenes → rotación → oportunidades;
  4. Clientes y comportamiento: repetición → retención → valor de cliente → segmentación.
