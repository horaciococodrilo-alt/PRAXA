# PRAXA — paquete de diseño de la app (para Claude Code)

Contenido:
- `PROMPT-CLAUDE-CODE.md` — prompt listo para pegar.
- `PANTALLAS.md` — las 7 pantallas (10 archivos de referencia), comportamientos y qué es placeholder.
- `diseno/tokens.css`, `diseno/componentes.md` — tokens y specs de componentes.
- `referencia/capturas/` — PNG de cada pantalla (1320px de ancho).
- `referencia/html/` — HTML/CSS renderizado por pantalla (estático, abrir en navegador).
- `referencia/fuentes-dc/` — fuentes originales `.dc.html` de la herramienta de diseño (solo lectura).
- `assets/` — logo Praxa (blanco y tinta), robot, logo Meta Ads. Los logos de Google Analytics / Google Ads van inline como SVG dentro de los HTML.

Límites conocidos (ver `PANTALLAS.md`): Inicio no tiene captura de referencia propia; opciones de selects y datos de perfil son placeholders; el Diagnóstico tiene texto filtrado de un LLM y su captura original se corta en el ítem 4; solo Diagnóstico existe en modo claro.
