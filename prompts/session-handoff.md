# Prompt — cerrar sesión y dejar handoff

Prepará el handoff sin agregar requisitos nuevos.

Actualizá `docs/plans/current.md` con:

- trabajo terminado;
- criterios cumplidos y pendientes;
- pruebas ejecutadas y resultados;
- decisiones aprobadas;
- decisiones pendientes;
- desviaciones respecto de la especificación;
- bloqueos;
- archivos que debe leer la próxima persona o agente;
- próximo ticket recomendado.

No conviertas sugerencias en decisiones aprobadas. No hagas commit o push salvo pedido explícito.
